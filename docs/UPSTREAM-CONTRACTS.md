# Upstream contract audit: z2k → OpenWrt

Аудит выполнен 2026-09-26 по нормативным документам и исходникам
`necronicle/z2k`. Документы/QA/CI проверены на `p-85.16`; code-path сравнен
также с базой адаптера `p-85.13`. Новейший релиз — `p-85.16`
(`2c1dc58d961e51d1845039c6741e4629f4e77be6`). Это не означает, что OpenWrt
уже собран из этого upstream snapshot: адаптер сохраняет pinned payload
`p-85.13` (`53cd74466094c60219b875073efbee50d058ddf3`), а отгружаемые
Keenetic WARP-бинарники остаются привязаны к `r-85.12`
(`0cc9207fde8aa60ba0b170a918f66643af7e364b`). Общий Go-исходник, который
OpenWrt собирает в CI, может включать явно перечисленные ниже безопасные
семантические backport-ы без подмены этих release pins.

Инвентарь behavioral/static suites, консолидации и mutation mapping см. в
[`docs/UPSTREAM-TEST-INVENTORY.md`](UPSTREAM-TEST-INVENTORY.md). Окончательные
сборки и Go-проверки выполняются только в repository CI.

В графе есть 32 контракта. Статусы описывают смысл поведения, а не сходство
реализаций. Для `PARTIAL` указано, какое подтверждение отсутствует. CI PASS
не считается проверкой на реальном роутере, а проверка процесса — доказательством
прохождения пользовательского трафика.

## p-85.16 change review

`p-85.13..p-85.16` contains 34 changed upstream paths, but no normative
Markdown, QA, CI or release-tooling file changed. Runtime-relevant changes and
their treatment are explicit in `HEALTH-01/02`, `WG-01`, `PROC-01`, `NDM-01`
and `YT-01`. Other p-85.16 changes are NDM hook rewrites/path repair and
webpanel cache-busters; NDM work is platform-only, while OpenWrt cache behavior
follows the signed payload manifest and package version. UPDATES manifest and
signatures remain pinned; no p-85.16 artifact is silently called the current
OpenWrt release.

## Status and action vocabulary

- Status: `PARITY`, `OPENWRT-EQUIVALENT`, `KEENETIC-ONLY / N/A`, `PARTIAL`,
  `MISSING`, `CONTRADICTED`, `STALE-DOC`.
- Action: `NONE`, `FIX-CODE`, `FIX-TEST`, `MERGE-TESTS`, `REPLACE-TEST`,
  `DELETE-DUPLICATE`, `ADD-CONTRACT`, `DOCUMENT-OPENWRT-DIFFERENCE`.

The matrix deliberately keeps target-router proof, packet-path/return-traffic
proof and soak as separate gates. A green CI run does not close those `PARTIAL`
rows.
